# SEA-ARMi version 1.3 — เวอร์ชันใหม่

ชุดหน้าเว็บและข้อมูลครบในโฟลเดอร์นี้ รวมการปรับตาม feedback 4Nov26

เปิด PowerShell ในโฟลเดอร์นี้ แล้วรัน:

```powershell
python -m http.server 8773 --bind 127.0.0.1
```

เปิด http://127.0.0.1:8773/ และเปิดหน้าต่าง terminal นี้ค้างไว้ หยุดด้วย Ctrl+C
อย่าเปิด index.html โดยตรง เพราะเว็บต้องโหลดข้อมูลผ่าน HTTP
แผนที่พื้นหลังต้องใช้อินเทอร์เน็ต

เทียบกับ version1-2: เพิ่ม UX/UI ใหม่ โลโก้ ตัวกรองติดด้านบน Dropdown เลือกหลายเชื้อ รายชื่อในกลุ่ม WHO ตัวกรองยาเฉพาะหลักฐาน ภาษาไทย/อังกฤษ คู่มือ และรูปแบบพิมพ์/PDF พร้อมเอาคอลัมน์จำนวนแถวต้นฉบับออก
